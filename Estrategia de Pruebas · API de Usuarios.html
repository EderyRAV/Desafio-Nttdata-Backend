Límites y agrupaciones

El _id exige exactamente 16 caracteres alfanuméricos. Se prueban los bordes del rango, no solo el centro.

caracteres especiales dentro de los 16 → probado

Formato válido, no registrado

16 caracteres alfanuméricos, id que no existe en base → 400/404 según endpoint.

Formato inválido

Longitud incorrecta o caracteres fuera de dominio → rechazo antes de buscar el registro.
